Backend changes made
====================

File changed: backend/run.py

What changed:
- Added app.run(debug=True, host="127.0.0.1", port=5000) at the end of the main block.

Why:
- The backend was creating the Flask app and database tables, but it never started the Flask development server.
- Because there was no app.run(...) call, running "python run.py" could finish and return to PowerShell instead of keeping the backend running.

How to run:
- Open PowerShell in the backend folder.
- Run: python run.py
- The backend should stay running at: http://127.0.0.1:5000
